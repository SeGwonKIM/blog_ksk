AIFFEL 과정에서 컴퓨팅적 사고(Computational Thinking)를 연습하는 과제를 진행했습니다. 임의의 도메인 문제 하나를 골라서 아래 네 단계로 정리해보는 방식이었습니다.

1. **분해 (Decompose)**: 큰 문제를 더 작은 단위로 쪼개기
2. **패턴 인식 (Pattern Recognition)**: 반복되거나 공통적으로 나타나는 요소 찾기
3. **추상화 (Abstraction)**: 핵심만 남기고 불필요한 세부사항 걷어내기
4. **알고리즘 (Algorithm)**: 처리 순서를 명확한 단계로 정리하기

연습용으로 "상담 결과를 정리해 고객에게 전달하는 작업을 자동화한다"는 가상의 문제를 잡고 진행해봤습니다.

- **분해**: 입력을 받는 단계 → 여러 항목을 계산/분석하는 단계 → 결과를 종합해 코멘트를 작성하는 단계로, 전체 과정을 여섯 조각으로 나눴습니다.
- **패턴 인식**: 반복되는 질문 주제(예: 세 가지 정도의 큰 카테고리)와 자주 등장하는 특정 요소가 있다는 걸 발견했습니다.
- **추상화**: 복잡한 분석 과정을 "요약 몇 줄 + 카테고리별 조언 한 줄씩"이라는 단순한 출력 형태로 압축했습니다.
- **알고리즘**: 입력 → 항목별 계산 → 결과 결합 → 카테고리별 해석 생성 → 최종 리포트 출력, 이렇게 순서를 명확히 정리했습니다.

## 느낀 점

막연한 문제를 그냥 코드로 옮기려 하면 어디서부터 손대야 할지 막막했는데, 분해-패턴-추상화-알고리즘 순서를 따라가니 실제로 무엇을 자동화하고 있는지가 훨씬 명확해졌습니다. 특히 "추상화" 단계에서 불필요한 디테일을 걷어내는 연습이 실제 코드 설계에도 그대로 적용될 수 있겠다는 생각이 들었습니다.

앞으로 실제 프로젝트를 시작할 때도 바로 코드부터 짜기보다, 이 네 단계를 먼저 짧게라도 정리하고 들어가 보려고 합니다.
